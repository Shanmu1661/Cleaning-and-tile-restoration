Getting Started

1. Installation & Quick Setup

AquaGleam is built using modern semantic HTML5, Vanilla JavaScript (ES6+), and Tailwind CSS. It requires zero Node.js build steps to run or edit, making it immediately previewable in any web browser, local server, or hosting platform (Netlify, Vercel, GitHub Pages, Apache, NGINX).

# Run using any local development server (e.g. VS Code Live Server or Python)
python -m http.server 8000
# Then open your browser at http://localhost:8000/pages/index.html

Design System

3. Customizing Colors, Typography & Spacing

All brand colors are controlled via CSS custom properties in assets/css/style.css as well as the Tailwind configuration script in each HTML file:

:root {
  --primary: #0284c7;      /* Primary Brand Cyan */
  --secondary: #0d9488;    /* Hygiene Teal */
  --accent: #f59e0b;       /* Amber Star Accent */
  --bg-body: #f8fafc;
}
Theme Engine

4. Dark / Light Mode Switching

Dark mode automatically detects OS preferences (prefers-color-scheme: dark) and remembers manual choices using localStorage.getItem('aquagleam_theme'). When toggled, the dark class is added to the <html> tag.

Bi-Directional

5. RTL (Right-to-Left) Language Setup

Clicking the RTL toggle button immediately sets dir="rtl" on <html>, reversing text alignment, breadcrumb arrows, before/after slider orientation, and float drawers. This setting persists in localStorage.

Niche Features

6. Interactive Components

  • Before/After Comparison Slider: Supports mouse and touch dragging, smoothly revealing clean tile beneath dirty grout.
  • Instant Cost Estimator: Real-time formula multiplying room size, treatment type, and square footage.
  • 4-Step Interactive Booking Wizard: Validates fields step-by-step and triggers a reference ID modal.
  • Toast Alert System: showToast(message, type, duration) handles non-intrusive feedback.
Integrations

7. Form Submissions (Formspree & Netlify)

To connect the contact form or newsletter to Formspree, replace the form action attribute:

<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">

For Netlify Forms, simply add data-netlify="true" to the <form> element.
